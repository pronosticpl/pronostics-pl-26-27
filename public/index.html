Règles bonus

Barème bonus

  • Champion : 10 points
  • Meilleure attaque : 5 points
  • Meilleure défense : 5 points
  • Meilleur buteur : 3 points
  • Meilleur passeur : 3 points
  • Meilleur gardien : 3 points
  • Meilleur joueur : 3 points

Vainqueur de journée

  • Le vainqueur de journée est calculé uniquement avec les points pronostics de la journée.
  • En cas d’égalité entre deux ou plusieurs joueurs, le mieux classé au classement général remporte la journée.
  • Une journée est validée seulement quand tous les matchs de cette journée sont terminés.
  • Si une journée est incomplète, les points déjà obtenus comptent dans le classement, mais aucun vainqueur de journée n’est désigné.
  • Dès que la journée est complète, le vainqueur de journée est calculé automatiquement.
  • Le vainqueur de journée peut changer la photo du groupe.

Égalité finale

  • En cas d’égalité à la fin du championnat, le départage se fait avec les points pronostics.
  • Si l’égalité reste, le départage se fait avec les points bonus.
  • Si l’égalité reste encore, le départage se fait avec le nombre de journées gagnées.
